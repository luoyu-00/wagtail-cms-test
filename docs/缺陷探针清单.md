# 缺陷探针清单

按模块列出可疑点的具体操作、预期、依据与不符时的定级。实测不符的才计入缺陷，实测结论见 `docs/探针实测记录.md`。

覆盖：页面 8 条、用户与权限 6 条、图片/文档 4 条、工作流 2 条、站点/重定向/集合/账户/报表 3 条，备用池 15 条。

## 一、页面管理（8 条）

### PRB-P01 预览链接能否被未登录用户访问　★重点
- 操作：编辑一个草稿页 → 点「预览」→ 复制预览窗口地址（形如 `/admin/pages/3/edit/preview/?mode=...`）→ 开无痕窗口直接访问
- 预期：要求登录或返回 403/404，不展示草稿内容
- 依据：未发布内容不应对外公开（预览是内部功能）
- 不符定级：**S1**（越权泄露未发布内容）

### PRB-P02 私有父页面的子页面是否真的继承限制
- 操作：给 Home 变更隐私为「私有」→ 用无痕窗口访问其子页面的前台地址
- 预期：子页面同样要求登录
- 依据：编辑页明确写着「私有设置也会应用到此页面的所有子页面」
- 不符定级：**S1**（声明与实际不符，且属权限泄露）

### PRB-P03 计划发布时间设为过去时间
- 操作：草稿页 →「设置计划」→ 发布时间填昨天 10:00 → 保存 → 看状态
- 预期：明确提示"发布时间不能早于当前时间"并拒绝；或立即发布并提示
- 依据：同模块其他时间类校验（到期时间）应有同样的约束；静默保存为"已计划"会导致页面永远不发布
- 不符定级：**S2**（内容无法按时发布且无提示）

### PRB-P04 到期时间早于发布时间
- 操作：发布时间设明天、到期时间设今天 → 保存
- 预期：提示两者矛盾并拒绝保存
- 不符定级：S3

### PRB-P05 页面标题 256 字符是否被静默截断
- 操作：标题粘贴 256 个 a → 保存 → 重新打开该页看标题实际长度
- 预期：提示超长并拒绝，或保存完整 256 字符
- 依据：静默截断属数据丢失，用户不知情
- 不符定级：S3（若截断后无任何提示）

### PRB-P06 列表分页超出末页
- 操作：页面列表只有 3 条时，把地址栏 `?p=99` 改进去
- 预期：回到有效页或提示无数据；不得 500
- 不符定级：S3

### PRB-P07 批量删除含子页面的页面时的提示
- 操作：勾选一个带 3 个子页面的父页面 → 批量删除 → 看确认页文案
- 预期：确认页明确列出将同时删除子页面数量
- 依据：删除不可恢复（系统无回收站），必须让用户看到影响范围
- 不符定级：S2（误删风险，数据不可恢复）

### PRB-P08 页面被锁定后他人能否覆盖保存
- 操作：admin 锁定页面 → editor01 在另一浏览器编辑同一页并保存
- 预期：提示页面已被锁定、拒绝保存
- 不符定级：S2（并发覆盖导致他人修改丢失）

## 二、用户与权限（6 条）

### PRB-U01 禁用用户后其已登录会话是否立即失效　★重点
- 操作：editor01 在浏览器 A 登录 → admin 在浏览器 B 取消其「有效」→ 回浏览器 A 刷新并尝试编辑
- 预期：被踢回登录页或提示无权限
- 依据：禁用应立即生效（安全常识）；Django 会话保存的是 user id，若中间件不校验 is_active 则仍然有效
- 不符定级：**S1**（已离职/禁用人员仍可操作系统）

### PRB-U02 用户名大小写是否算重复
- 操作：新建用户，用户名填 `Editor01`（已存在 `editor01`）→ 保存
- 预期：拒绝创建（用户名不应区分大小写）
- 不符定级：S3（可创建易混淆账号，存在冒充风险则升 S2）

### PRB-U03 删除用户后其创建的页面归属
- 操作：删除 editor01 → 打开它创建过的页面 → 看作者/创建人显示
- 预期：页面保留，创建人显示为未知/已删除；列表与详情不报错
- 不符定级：S3（若报 500 则 S2）

### PRB-U04 删除仍有成员的组
- 操作：删除含 1 名成员的组 → 看提示与删除后该成员的权限
- 预期：提示成员将被解绑；删除后成员权限被清除
- 不符定级：S3

### PRB-U05 viewer01 直接输入各类受保护 URL
- 操作：viewer01 依次访问 `/admin/pages/3/edit/`、`/admin/pages/3/delete/`、`/admin/images/`、`/admin/users/`、`/admin/reports/site-history/`
- 预期：全部 403 或无权限提示，不渲染任何数据
- 不符定级：**S1**（越权）；仅某页可访问则 S2

### PRB-U06 权限变更是否需要重新登录
- 操作：给 editor01 的组新勾选「发布」→ editor01 仅刷新页面（不重登）→ 尝试发布
- 预期：立即生效（权限按请求实时计算）
- 不符定级：S3

## 三、图片与文档（4 条）

### PRB-M01 文档恰好 10MB 是否允许
- 操作：`truncate -s 10485760 big.pdf` 生成文件 → 上传
- 预期：允许上传（上限取等号）
- 依据：`WAGTAILDOCS_MAX_UPLOAD_SIZE = 10*1024*1024`，通常判 `size > max` 才拒绝
- 不符定级：S3（边界判断与配置文档不一致）

### PRB-M02 10MB+1 字节是否被拒且提示明确
- 操作：生成 10485761 字节文件上传
- 预期：提示文件超过 10MB，且提示里给出实际上限
- 不符定级：S4（提示缺失或文案错误）

### PRB-M03 扩展名白名单外的文件
- 操作：上传 `a.exe`、`b.csv`（csv 在白名单，应允许）、`c.txt` 改名 `c.pdf`
- 预期：exe 被拒；csv 允许；改名文件按内容/扩展名至少一层拦截
- 依据：`WAGTAILDOCS_EXTENSIONS = [csv, docx, key, odt, pdf, pptx, rtf, txt, xlsx, zip]`
- 不符定级：S2（若能上传可执行文件）

### PRB-M04 删除被页面引用的图片
- 操作：把图片插入某已发布页面 → 删除该图片 → 刷新前台页面
- 预期：删除时警告引用位置，或允许删除但前台不出现 500
- 不符定级：S2（前台报错）/ S3（静默失效图）

## 四、工作流（2 条）

### PRB-W01 审核中的页面能否被编辑者随意修改　★重点
- 操作：editor01 提交页面审核 → 不退出，直接修改正文并保存 → 看状态是否变为"已修改/需重新审核"
- 预期：锁定编辑，或修改后自动退回待审核
- 不符定级：S2（可绕过审核直接改内容）

### PRB-W02 驳回后能否重新提交且有驳回原因
- 操作：admin 驳回并填写原因 → editor01 查看页面
- 预期：能看到驳回原因、可修改重新提交
- 不符定级：S3

## 五、站点 / 重定向 / 集合 / 账户 / 报表（3 条）

### PRB-O01 循环重定向是否被拦截
- 操作：建 `/t-a/ → /t-b/`，再建 `/t-b/ → /t-a/` → 访问 `/t-a/`
- 预期：保存时检测循环并拒绝；至少访问时给出明确错误而非无限跳转
- 依据：浏览器会报 ERR_TOO_MANY_REDIRECTS，用户侧表现为打不开
- 不符定级：S2

### PRB-O02 删除含内容的集合
- 操作：集合内放 1 张图片 → 删除该集合并确认 → 看图片是否还在
- 预期：提示集合非空或要求先移走内容；不得静默连图片一起删除
- 不符定级：S2（数据丢失）

### PRB-O03 站点主机名+端口重复 / 默认站切换
- 操作：新增站点填 `localhost` + `80`（已存在）→ 保存；再把另一站点设为默认站 → 访问 `127.0.0.1:8001/`
- 预期：重复组合被拒；切换默认站后前台返回新站根页面
- 不符定级：S3
