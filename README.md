# Wagtail 8.1 内容管理后台 功能测试

对开源 CMS Wagtail 8.1（Django 6.1.3）后台管理端的一轮功能测试，覆盖 12 个模块、84 个功能点，设计用例 250 条，缺陷提交在本仓库 Issues。

## 环境

| 项 | 内容 |
|---|---|
| 系统 | Wagtail 8.1 / Django 6.1.3（BSD-3 开源版） |
| 部署 | 本地 `manage.py runserver 127.0.0.1:8001`，SQLite |
| 浏览器 | Chrome，F12 常开 |
| 语言 / 时区 | zh-hans / Asia/Shanghai |
| 账号 | admin（超级用户）、editor01（编辑组）、viewer01（无组）、disabled01（已禁用） |

## 方法

- 功能清单靠界面走查 + 路由核对产出，不依赖文档（系统无正式需求文档）
- 每个功能点按正例 / 反例 / 边界 / 权限四象限展开，复杂功能点四类必齐，简单功能点至少 2 条
- 同一判断分支只写一条，不重复计数
- 预期结果按官方文档 > 同模块既有行为一致性 > 同类产品惯例 > 个人判断的顺序取依据；最后一类标「待确认」并记入 `docs/待确认清单.md`
- 执行前跑 43 条 P0 冒烟，主干通过再进全量；失败当场截图（界面 / 结果 / F12 请求）

## 缺陷

提交在本仓库 Issues，标签分两级：

- 严重程度：`S1-致命` `S2-严重` `S3-一般` `S4-轻微`
- 处理状态：`待修复` `待验证` `已关闭`

每条缺陷记录环境、前置条件、复现步骤、预期（附依据）、实际（含 HTTP 状态码）、复现概率、截图、影响与规避方案。新建 Issue 自动带出模板：`.github/ISSUE_TEMPLATE/bug.md`。
